The tradeoff: that money is then locked into the house. You can't pull it back out if you need cash.

**Invest it instead**, aiming for a return above the loan's 9%. You already have Fund-A running as a SIP, in the high-risk bucket — the mechanism here is expected return versus risk versus how long the money stays invested, which is its own thread we could go into. The core tension: prepaying is a guaranteed 9% saved; investing is an uncertain shot at more, with the money staying liquid.
