# Home journey and state matrix

## Journey

1. **Enter:** authenticated user arrives after onboarding, login or tab selection.
2. **Orient:** verify account identity, last refresh and whether the page is current, partial or offline.
3. **Read:** inspect family totals and explicit gaps without a synthetic net-worth verdict.
4. **Understand:** open Portfolio Health coverage or Arya for an explanation.
5. **Explore:** deliberately choose a calculator, scenario, teaching prompt or learning-progress detail.
6. **Manage:** open personalization, optional financial context, privacy, export, logout or deletion.
7. **Return:** Home refreshes each source; a local failure does not erase successful sections.
8. **Exit/switch:** logout or account switch clears prior-subject content before the next subject renders.

## State matrix

| State | What appears | Available action | Must never happen |
|---|---|---|---|
| Loading | Account shell plus shape-matched skeletons | Wait; account controls remain reachable when safe | ₹0 placeholders or layout jumps |
| Empty | “Nothing recorded yet” and equal Add / Ask Arya / Explore routes | Choose any route or leave | Shame, completeness score or forced capture |
| Partial | Known totals plus named unknown/unreadable/excluded counts | Open the affected family | Silent omission or false grand total |
| Valid | Current timestamp, three neutral family totals, all eight areas | Open any route | Recommended priority or winner |
| Invalid value | Family stays visible with readable-count warning | Review affected records | Coerce malformed data to zero |
| Stale | Last-known values labelled with their timestamp | Retry refresh or continue knowingly | Present stale values as current |
| Section failure | Only the affected block shows failure and retry | Retry that block | Whole-page empty state |
| Offline | Last-known view, offline banner, no silent resend | Retry manually after connection returns | Forced logout for a network blip |
| Permission denied | Financial content clears; re-auth route appears | Sign in again or leave | Prior-subject content behind banner |
| Account transition | Neutral loading shell identifies destination account | Wait or cancel at auth surface | Old-account flash or late-response overwrite |
| Optional invite | One dismissible personalization card | Personalize or “Not now” | Blocking Home or implying required disclosure |
| Reward | One dismissible learning fact or factual streak | Dismiss or open progress | React to wealth, debt or score change |
| Recovery | Successful sections remain; retried section replaces only itself | Continue | Duplicate cards or reordered hierarchy |

## Controlled fixtures

- **Mira:** mixed financial picture, one unreadable investment value, one unclassified record, 3/4 Health areas.
- **Kabir:** sparse/empty baseline with no zeros implied.
- All numbers are hypothetical and stay inside the browser's in-memory state.
