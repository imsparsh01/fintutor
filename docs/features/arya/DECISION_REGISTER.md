## Open decisions discovered

No new production decision is required to run the prototype. The following become decisions only if owner
validation requests production change:

| Potential fork | Routing if requested |
|---|---|
| Add persistent or cross-session chat history | Tier 3: privacy/retention plus parked MVP scope |
| Change what data reaches the model or how masking works | Tier 3: sensitive-data/compliance interpretation |
| Change teaching/advice, product-name, ranking or surfacing boundaries | Tier 3: standing-principle/compliance interpretation |
| Add a new model, service, library or production architectural pattern | Tier 3 under repository hard stop |
| Add production UI copy/state using only settled rules | Route after validation; Tier 1 only if one answer is clearly compelled, otherwise Tier 2 |
| Change calculation, rate, comparison or money consequence | Tier 3: user-relied-on money logic |
