# D-167 — Scenario taxonomy stays two-level; focused explorers remain contextual

- **Tier:** 2 — REVIEW-FLAGGED; interprets D-104/D-148's approved suite hierarchy.
- **Decision:** Tools uses the user-facing category “Scenarios” for the five dedicated scenarios. The four
  focused explorers use an “Explore this mechanism” action from eligible record/context surfaces and are not
  duplicated as context-free Tools cards. “Focused explorer” remains an internal documentation term.
- **Lenses:** Compliance PASS — equal contextual actions add no urgency, product name or ranking; Product PASS
  — users see the financial question rather than product architecture; Technical PASS — current contextual
  routes remain authoritative; Cost-and-scope PASS — no duplicate flow or index machinery.
- **Why:** A third catalogue taxonomy would add terminology without improving the user's decision authorship.
  Context supplies eligibility, provenance and a reliable return destination.
- **Reversibility:** Copy and route presentation only; no stored data, formula or schema change.
- **Date:** 29-Aug-2026
